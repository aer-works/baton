#
#   - One Python regex (re.search semantics -- matches anywhere on the line) per line.
#   - '#' starts a comment; blank lines are ignored.
#   - A HIT withholds that one deliverable (a stub with the pattern's INDEX ships instead; the
#     pattern text itself is never logged or uploaded).
#   - A MISSING or unreadable file fails CLOSED: every deliverable in that run is withheld, not
#     just the ones this file would have caught.
#

# deliverables might contain -- so secretpatterns.local.txt stays out of this public repo. Only this
